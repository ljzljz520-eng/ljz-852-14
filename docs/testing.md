# 测试计划

## 1. 测试范围
- **功能测试**: 搜索功能、详情页展示、磁力链复制。
- **兼容性测试**: 响应式布局在桌面端和移动端的表现。
- **性能测试**: 并发搜索时的响应速度。

## 2. 手动测试用例

| ID | 模块 | 测试步骤 | 预期结果 |
| :--- | :--- | :--- | :--- |
| TC01 | 首页 | 访问 `http://localhost:3000` | 页面正常加载，并在搜索框下方看到提示语 |
| TC02 | 搜索 | 输入 "Ubuntu" 并提交 | 列表页显示 Ubuntu 相关 ISO 资源 |
| TC03 | 搜索(部分) | 输入 "Ubu" 并提交 | 前缀模糊搜索生效，列表页显示 Ubuntu 相关 ISO 资源 |
| TC04 | 详情 | 点击搜索结果中的条目 | 进入详情页，显示文件列表和文件大写 |
| TC05 | 复制 | 点击“复制磁力链”按钮 | 提示“已复制”，剪贴板中存在 magnet 链接 |
| TC06 | 演示数据 | 执行 `php scripts/seed_demo.php` | 导入 50 条演示记录，末尾 9 项搜索自测全部 OK，搜索 `Ubuntu`、`三国`、`回合制`、`ubuntu-24.04-desktop`（文件名片段）等有结果 |
| TC07 | 幂等/清理 | 连续执行两次 seed_demo.php，再执行 `--clean` | 记录数始终为 50 不增长，清理后 MySQL 与 Manticore 中 `deadbeef` 前缀记录归零 |
