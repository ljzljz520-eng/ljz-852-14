# 用户手册

## 1. 简介
欢迎使用 Manticore DHT 搜索引擎。本系统提供全网磁力资源的快速检索服务，专注于速度与隐私。

## 2. 如何使用

### 2.1 搜索资源
1. 打开首页。
2. 在搜索框输入关键词，支持标题、标签与文件名检索：
   - ✅ 标题/标签: `Ubuntu`, `Python`, `三国`, `回合制`
   - ✅ 前缀模糊: `Ubu`, `Pyth`（自动按词干前缀展开）
   - ✅ 文件名片段: `ubuntu-24.04-desktop`, `big_buck_bunny_1080p`
   - 多个关键词用空格分隔，结果需同时包含所有关键词。
3. 点击“搜索”按钮或按回车键。

### 2.2 查看详情
在搜索结果列表中，点击资源标题即可进入详情页。详情页包含：
- **基本信息**: 资源名称、大小、收录时间。
- **磁力链接**: 点击“复制磁力链”即可获取下载链接。
- **文件列表**: 预览资源内包含的所有文件。

### 2.3 迅雷下载
在详情页，如果已安装迅雷等支持软件，尝试点击“打开”按钮可能会直接唤起下载工具。如果浏览器拦截，请使用“复制磁力链”功能后在下载软件中新建任务。

## 3. 常见问题
- **Q: 为什么搜不到结果？**
  - A: 请确认输入的关键词是否拼写正确，或关键词是否过于冷门；多关键词之间为“且”关系，可适当减少关键词。
- **Q: 支持哪些模糊搜索？**
  - A: 支持标题、标签和文件名的词干前缀匹配（如 `Ubu` 可匹配 `Ubuntu`），也可直接用文件名片段（如 `ubuntu-24.04-desktop`）检索。
